# Logos

La marque Convix est le **C fendu** : un C elliptique épais coupé à l'horizontale ; la moitié haute glisse à droite, la moitié basse à gauche — deux devises qui s'échangent. Le wordmark reprend la coupe sur son C et donne au X un trait montant violet.

- `convix-app-icon.svg` — icône d'app 1024px, C blanc sur tuile violet→orchid. Stores, écran d'accueil, favicon ≥ 32px.
- `convix-app-icon-dark.svg` — variante sombre (tuile `hero-base`, C en dégradé) pour les icônes « dark » iOS / thèmes sombres.
- `convix-mark-gradient.svg` — le C seul en dégradé lilac→violet→orchid, sur fonds sombres.
- `convix-mark-violet.svg` — encre unique `violet` (#7a45f0), sur fonds clairs.
- `convix-mark-white.svg` — encre unique blanche, sur `hero-base`, `violet` ou photo sombre.
- `convix-mark-ink.svg` — encre unique `ink` jour (#19122e), impression monochrome.
- `convix-wordmark-white.svg` — « CONVIX » blanc, X montant lilas (#b48cff), sur fonds sombres.
- `convix-wordmark-ink.svg` — « CONVIX » encre #19122e, X montant `violet`, sur fonds clairs.
- `convix-wordmark-mono-white.svg` / `convix-wordmark-mono-ink.svg` — versions une couleur (gravure, tampon, fax).
- `convix-lockup-white.svg` / `convix-lockup-ink.svg` — icône + wordmark horizontaux, pour site, slides, signatures.

Règles : zone de protection = la moitié de la hauteur de l'icône sur chaque côté ; taille minimale 20px pour le C seul, 72px de large pour le wordmark. Ne pas recomposer le wordmark avec une police, ne pas fermer la fente du C, ne pas inverser le sens des glissements.
