# Flags

Drapeaux circulaires de référence, 64px, dessinés simplement pour les maquettes et les previews (pas d'étoiles exactes sur US, feuille d'érable stylisée sur CA). En production, servir un jeu complet de drapeaux ronds (par ex. le paquet open source `circle-flags`) et le mettre en cache hors ligne.

- `ci.svg` — Côte d'Ivoire, utilisé pour **XOF** (franc CFA BCEAO) sur les écrans ivoiriens.
- `eu.svg` — Union européenne, **EUR**.
- `us.svg` — **USD** · `gb.svg` — **GBP** · `ng.svg` — **NGN** · `gh.svg` — **GHS** · `ma.svg` — **MAD**
- `cn.svg` — **CNY** · `jp.svg` — **JPY** · `ca.svg` — **CAD** · `ch.svg` — **CHF** · `dk.svg` — **DKK**

Toujours afficher via `Flag`, qui ajoute le filet `line` autour du disque.
