# Icons

Jeu d'icônes Convix dessiné pour le système : grille 24px, trait 1.75, extrémités et jointures rondes. Les fichiers sont en encre unique `ink` jour (#19122e) ; dans l'app, utiliser le composant `Icon` (tracé en `currentColor`) ou recolorer à l'import (SVGR).

- `home`, `globe`, `keypad`, `bell`, `settings` — destinations de la tab bar.
- `swap` — inverser la paire. `backspace` — touche effacer du clavier.
- `search`, `mic` — champ de recherche. `plus`, `minus` — ajouter / retirer une devise.
- `trend-up`, `trend-down` — sens de variation d'un taux (toujours avec `rise` / `fall`).
- `clock` — fraîcheur du taux. `refresh` — actualiser. `star` — favori.
- `chevron-right`, `close`, `check` — navigation, fermeture, sélection.
