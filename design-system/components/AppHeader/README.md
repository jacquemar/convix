# AppHeader

L'en-tête de l'app : icône Convix, lockup en capitales sur deux lignes (`lockup`) et un emplacement à droite pour l'avatar.

**Le consommateur fournit** : `title` / `subtitle` (par défaut « Convix » / « Convertisseur ») et `trailing` (en général `<Avatar/>`).

- À poser dans un `HeroCard` (le texte suit `--ink`, remappé sur `on-hero`).
- Le lockup reste sur deux lignes maximum ; pas de troisième ligne, pas de sous-titre marketing.
