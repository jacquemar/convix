# Icon

Icône du jeu Convix en SVG en ligne, tracée en `currentColor` : la couleur vient du `color` du parent.

**Le consommateur fournit** : `name`, `size` (24 par défaut), `title` seulement si l'icône porte du sens seule.

- Grille 24px, trait 1.75, extrémités et jointures rondes. Ne pas mélanger avec une autre bibliothèque d'icônes dans un même écran.
