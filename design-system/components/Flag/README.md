# Flag

Drapeau circulaire avec un filet `line` pour qu'un drapeau clair ne se fonde jamais dans le fond.

**Le consommateur fournit** : `src` (SVG carré ou rond), `alt` (vide quand le code est écrit à côté), `size` (36 par défaut).

- Les drapeaux de référence sont dans `assets/Flags/`. En production, servir un jeu complet (voir le README du groupe Flags).
- Devises multi-pays (XOF, XAF, EUR) : drapeau du pays de l'utilisateur pour XOF/XAF, drapeau européen pour EUR.
