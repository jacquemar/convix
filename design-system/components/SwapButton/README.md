# SwapButton

Carré de verre qui inverse les deux devises ; ses flèches font un demi-tour à chaque pression.

**Le consommateur fournit** : `onSwap`, et un `label` si la langue change (« Inverser les devises » par défaut).

- 36px dessinés, zone tactile 44px. Bordure `line-strong` (3:1).
- Une seule action : inverser. Pas de menu, pas d'appui long.
