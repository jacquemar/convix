# Button

Bouton pilule avec libellé Unbounded en capitales (`button-label`) : `primary` violet, `secondary` en verre bordé, `ghost` en texte d'accent.

**Le consommateur fournit** : le libellé (un verbe : « Convertir », « Actualiser »), `variant`, `icon` optionnelle, `block` pour la pleine largeur.

- Un seul `primary` par écran. Le bouton primaire n'a pas de halo : seul le FAB brille.
- Désactivé : opacité 45 %, et dire pourquoi à côté (« Hors ligne »).
