# AppIcon

L'icône d'app Convix dessinée en ligne : le C fendu blanc sur tuile violet→orchid (`brand`) ou en dégradé sur tuile `hero-base` (`dark`).

**Le consommateur fournit** : `size` (40 par défaut), `variant`, `title` (« » quand le nom est écrit à côté).

- Pour les stores et l'écran d'accueil, utiliser les fichiers `assets/Logos/convix-app-icon*.svg` (1024px).
- Ne pas recolorer, ne pas ajouter d'ombre portée, ne pas remplacer le C par une lettre de police.
