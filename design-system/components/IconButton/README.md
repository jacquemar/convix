# IconButton

Bouton rond icône seule : `outline` (listes), `glass` (sur le hero ou un sheet), `violet` (action principale).

**Le consommateur fournit** : `icon`, `label` (obligatoire, nom accessible), `variant`, `size` (`sm` 28 / `md` 36 / `lg` 44).

- La zone tactile est toujours ≥ 44px, quelle que soit la taille dessinée.
